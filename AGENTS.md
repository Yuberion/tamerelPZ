# Project Rules & Boundaries

> [!CAUTION]
> ### 🚨 ПРАВИЛО НАИВЫСШЕГО ПРИОРИТЕТА: Разработка, портирование и папки `*_Port`
> При создании собственных модов или модификации/переделке/портировании существующих модов:
> 1. **Рабочая папка**: Вся разработка, создание новых файлов, модификации и адаптация кода ведутся **ИСКЛЮЧИТЕЛЬНО** в папке, содержащей в своём названии маркер **`_Port`** (например, `<ModName>_Port`).
> 2. **Неприкосновенность оригинала**: Папка оригинального мода является **СТРОГО НЕИЗМЕНЯЕМОЙ (READ-ONLY)**. Категорически запрещено изменять, перезаписывать или удалять исходные файлы оригинального мода.
> 3. **Рабочий процесс**: Оригинал используется только для чтения/анализа — вся чистая сборка, новые фичи B42 и изменения пишутся только внутри папки `*_Port`.

## 3. О проекте: PZ MANAGEMENT

**PZ MANAGEMENT** — это модульное десктопное приложение для управления, анализа, разработки и отладки модов игры **Project Zomboid** (поддержка сборок **Build 41** и **Build 42**).
- **Стек**: Electron, React 19, TypeScript, electron-vite.
- **Архитектурный принцип**: *Zero runtime dependencies* (минимализм во внешних зависимостях, максимальная автономность и безопасность при работе с файлами пользователя).

### Основные модули приложения:
1. **Stalker (Explorer)**: Автодетекция Steam / Workshop / папок игры. Парсинг `mod.info`, классификация модов по типам (карты, транспорт, оружие, сущности B42 и т.д.), проверка совместимости B41/B42, построение дерева зависимостей (`require=`), виртуализированный 3-панельный инспектор файлов.
2. **Loadout**: Управление порядком загрузки модов для клиента (`Zomboid/mods/default.txt`) и серверов (`Zomboid/Server/*.ini`). Интеллектуальная сортировка с учётом зависимостей (*Fix order*), поддержка карт (`media/maps`), привязка Workshop ID и профили.
3. **Workbench**: Инструменты автора модов — скаффолдинг структуры мода (B41/B42, `craftRecipe`, `PZAPI.ModOptions`), визуальный и текстовый редактор `mod.info`, статический валидатор (Lua-парсер с белым списком 217 событий, скрипты предметов/крафта, переводы B41/B42, теги Workshop), упаковка для Steam Workshop.
4. **Ledger**: Анализатор краш-логов и консольного вывода (`console.txt`, `Logs/*_DebugLog.txt`), свертывание стектрейсов, сопоставление ошибок с конкретными установленными модами (*Mod attribution*).
5. **Tools**:
   - **FBX Forge**: собственный конвертер 3D-моделей в `.fbx` (DirectX `.x` форматы игры, `.obj`, `.stl`, `.ply` и др. + опциональный fallback на `assimp`).
   - Мост с Notepad++ для подсветки синтаксиса скриптов PZ.
